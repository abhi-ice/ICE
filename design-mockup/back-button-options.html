Honest read of where modern SaaS landed in 2026

  • Linear, Notion, Vercel, Stripe Dashboard → option A (breadcrumb). The breadcrumb does both jobs: shows hierarchy + provides back-nav. No "back button" widget at all.
  • GitHub, Asana → option B (round icon-only) on detail pages. Recognizable enough that the icon alone is fine.
  • Procore → option E (pill with destination). Construction-specific UI tends to be more literal — "Daily reports" reads better to field PMs than a generic "back".
  • Almost nobody uses your current pattern (text link in the action row) anymore — that was a 2018-2020 convention.

My recommendation

  • Option A (breadcrumb) if you want maximum modernness + free context indicator.
  • Option E (pill "Daily reports") if you want to be more literal for federal PMs — the destination name + a clear button shape leaves zero ambiguity.
  • I'd ship A. E is a safe fallback.
