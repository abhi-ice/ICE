What changed from v1

01

One section, not two

Upload + tag and Pin + AI review share the same photos, so they share one section. Upload + tag sits as the header action (top-right) — always reachable, never stuffed in with the grid.

02

Newest full, rest one-line

Only the latest review shows in full. Run 4–5 and the older ones collapse to a single tappable line — the DR stays short instead of growing a wall of AI text.

03

Open → edit → send

Tapping a collapsed review opens a dialog with the editable text + severity. Tweak it, Copy, or Send to Safety / Send to QC — which jumps to that form with the text + severity prefilled.

04

Severity always visible

Both the full card and the one-line rows lead with the severity chip (Clear / N concerns / critical), so the verdict reads at a glance without opening anything.

05

Copilot loses Send-to-QC/Safety

Since this is now the dedicated home for photo findings, the Send to QC / Send to Safety buttons get removed from the AI Copilot (Foreman) chat responses — one clear place, no duplication.

06

Lens-matched send

A Safety review offers Send to Safety; a QC review offers Send to QC. The pinned photos ride along, so the new event is photo- and task-linked from the start.
