Button styles — round 2

Six fresh patterns sourced from outside the standard enterprise-SaaS canon (Stripe / Linear / Notion / etc. were in round 1). These lean editorial, architectural, and tool-native — sources include Read.cv, Pitch, Cron, Are.na, Apple Music, Things 3, Mirror, Vercel docs, and the new macOS Tahoe controls. Light panel uses the actual SiteOps cream-paper background (#f5f1ea); dark panel uses the noir surface — so the comparison is honest to where these buttons will actually live.

Why this works: the rule is rigid — everything in the UI is monochrome. Only ONE button per screen gets the emerald accent + a faint emerald glow ring. The eye knows immediately where to land. Cron does this strictly; Linear's sidebar new-issue button is the same idea. Tonal grayscale primary (white-on-dark / dark-on-light) plus barely-there grayscale secondary (transparent + slight tint on hover).

Use if: you want a strong "what should I do next" signal on every page without visual noise. Most respectful of users' eyes. Avoid if: some pages legitimately need two equally-weighted CTAs (e.g. "Approve" and "Reject" on the Approvals queue — neither one "wins").

My new picks: G (editorial) or J (saffron palette-native)

Of these six, two genuinely fit the brief "subtle, classy, sober, modern, efficient, aesthetic, palette-aware":

Option G — Editorial typography
Most aesthetic. Underline-link secondaries make the page read like a printed report. Primary is solid dark (paper-on-ink) so the hierarchy is unmistakable. Emerald reserved for ONE brand action per screen.
Best if: SiteOps is documents-and-records-first. GSA / NYCHA contracts have a natural editorial feel — this pattern earns its keep on every page.
Option J — Saffron palette-native
Drops emerald-on-everything for navy primaries + saffron brand CTA — both pulled from the Palette B "Warm Concrete" direction in your own CLAUDE.md. Reads as federal-construction, not Y Combinator.
Best if: you want the visual identity to lean into the cream-paper warm-concrete brand you already documented but never fully applied to buttons.

Two ways to hybrid: use Option G's button shapes with Option J's colors (navy primary, saffron brand, editorial underlines). Or pair Option I (color-pop monochrome) with Option H's pressed-inset secondary buttons for a Cron / Things 3 feel that still has tactile polish.

Quick reminder noted: next sweep of button labels also drops the leading "+" — "New daily report" instead of "+ New daily report", since the icon (when present) already says "add". Cleaner + more meaningful.
