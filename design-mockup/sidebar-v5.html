What's new (and why)

  • ⌘K Jump-to bar at the top — Linear's killer feature. Type any page name, RFI number, task code → jump instantly. Power users never have to scroll the sidebar again.
  • Color-coded section dots (indigo / emerald / amber / blue / violet / teal / slate) — at-a-glance section parity. Eye recognizes "I'm in the green section = Daily Ops" before reading the label.
  • Collapsible sections with chevrons — Notion pattern. Resources + System collapsed by default (rarely touched). Frees the top 70% of the sidebar for the daily-use stuff.
  • Active item: 3px emerald rail on the left + emerald-tinted bg — unmistakable focus, doesn't depend on color alone (accessibility).
  • Inline keyboard hints ⌘1, ⌘2, ⌘3 on the most-used items (Dashboard, Projects, Daily Reports) — train muscle memory.
  • Semantic count badges on the right of each item — emerald (approvals waiting), amber (RFIs/delays pending), rose (field issues/aging — needs attention), blue (submittals/edit requests), slate (neutral counts). Visible without opening the section.
  • Tighter typography (12px / 1.4 line-height) + 1px row gap — fits the whole nav without scrolling on a 720p monitor.
  • Cleaner nested items — no per-item left border (those were the "||||" stack you saw). Just indent + slightly muted color.
  • Footer with version + help + theme micro-toggle — moves the theme button out of the topbar (saves topbar space) and gives a clear "you're on v0.3" anchor.

If you like this, the wire-up is ~300 lines:

  • Sidebar.jsx — restructure to use new .sb-* classes + section collapse state
  • index.css — port these styles (already self-contained in this mockup)

  • Per-section collapse state persisted to localStorage
