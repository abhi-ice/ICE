Honest assessment of your pick

Your colors are exactly right — silver-on-dark / dark-on-light primary with emerald reserved for the brand CTA is the strongest pattern in modern SaaS (Stripe / Linear / Vercel all use this). It will look classy and sober on both themes and ages well.

The "glass / backdrop-blur" effect from Option D, however, won't deliver here. Glass needs visual texture behind the button (gradient, photo, particles) to look like glass. On the current flat-color backgrounds the blur is imperceptible — users will just see a slightly translucent rectangle, which can read as "is this button broken?".

My take: take the silver/grey/emerald palette you picked from Option D, drop the literal glass blur, and add a very subtle inset 0 1px 0 rgba(255,255,255,0.X) highlight + 0 1px 2px rgba(0,0,0,0.X) shadow. That gives the same tactile / premium feel as glass but is honest about being a solid button on a flat surface. Backdrop-blur stays available on a single variant (dark secondary) because the noir surface has just enough texture to show it. Showing the full system below — judge whether this is what you wanted.

Variant → color mapping
Primary (silver / dark-grey):
The page's main action. ONE per surface. Silver #e4e4e7 on dark, dark-grey #27272a on light. Subtle inset highlight + 1px shadow gives the premium feel without literal glass.
Secondary (translucent / outline):
Supporting actions. Dark uses 6% white + backdrop-filter: blur(8px) — only place the glass effect actually shows because dark surfaces have just enough tonal variation behind. Light uses solid white with a hairline ring.
CTA (emerald):
Reserved for the brand action when Submit is NOT the right word — "Coordination" on its own page, landing-page "Get started", top-of-funnel actions. Limit: one emerald per visible surface.
Danger / Destructive:
Solid rose for in-modal "Delete X"; outlined-rose for inline row Delete that hasn't been confirmed yet.
Ghost (Cancel / Skip):
Transparent, no border, muted text. Hover tints with 4% black/white. Used for non-actions that need to be present but quiet.
