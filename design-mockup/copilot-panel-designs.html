Reasoning — pick on these axes

Distinction from the main app surface — strongest is B (always-dark tool) and D (navy header is unmistakable). Weakest is C (frosted glass is subtle by design).
Brand cohesion with the emerald palette — best is D (uses emerald as accent, navy as authority). A swaps emerald for copper which breaks brand. B keeps emerald but uses dark slate which is off-brand.
Psychological signal — A reads "slow thought, intellectual"; B reads "developer tool"; C reads "polite overlay, gets out of the way"; D reads "enterprise authority, this is the brain".
Implementation risk — C requires backdrop-filter support which can be heavy on Chromebooks/older Windows; A introduces copper which is a new color we don't use elsewhere; B is simplest (always dark); D is moderate (navy header is one new band).
My recommendation: D — it's the only option that strengthens your brand (emerald) while signaling "this is the AI surface" via the dark authoritative header. It also works identically across themes which simplifies QA. Tell me which one (or a hybrid like "D header + C bubbles") and I'll ship it.
